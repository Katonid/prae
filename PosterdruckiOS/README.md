# Posterdruck

iOS-App (iPad und iPhone, iOS 17): Bilder laden, Posterformat mit
Beschnitt wählen (z. B. DIN A2 hochkant, 3 mm Beschnitt → Datenformat
426 × 600 mm) und eine druckfertige PDF für die Druckerei erstellen.

- Jedes Bild wird ein Poster (eine PDF-Seite).
- Beschnitt als rote gestrichelte Linie in der Vorschau.
- Ausschnitt verschieben, zoomen, drehen; „Ganzes Bild“ mit Hintergrundfarbe.
- Auflösungsprüfung in dpi je Poster.
- PDF mit TrimBox/BleedBox, wahlweise Schnittmarken, eine Datei oder
  eine je Poster.
